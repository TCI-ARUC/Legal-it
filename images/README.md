# Afbeeldingen

## Ontwerpbeelden (`images/ontwerp/`)
Beelden uit het websiteontwerp. Ze zijn breed (ongeveer 4:1) en worden met `object-fit: cover` getoond.
Vervang een bestand door een scherpere versie met dezelfde naam; de site past zich vanzelf aan.

| Bestand | Gebruikt in |
|---|---|
| `hero-overleg.webp` / `.jpg` | homepage, hero |
| `vak-advocaten.webp`, `vak-accountants.webp`, `vak-notarissen.webp` | homepage, vakken onder de hero (vierkant) |
| `justitia.webp` | hero-strook advocatenpagina's |
| `rekenmachine.webp` | hero-strook accountantspagina's |
| `lakzegel.webp` | hero-strook notariaatpagina's |
| `boekenkast.webp` | ISO-band homepage, back-up, Wwft, kennis |
| `zuilen.webp` | informatiebeveiliging, partners, software advocatenkantoor, AI-beleid |
| `laptop-slot.webp` | cybersecurity, veilig mailen, managed firewall |
| `hamer.webp` | AI en compliance, checklist IT-partner |
| `laptop-teams.webp` | werkplek, Microsoft 365-beheer, telefonie, AI en automatisering |
| `kantoor.webp` | diensten, over ons, contact, netwerk, homepage (waarom Legal IT) |
| `overleg.webp` | reserve |

Aanbevolen formaat voor vervangende bestanden: minimaal 1600 px breed, zonder tekst in het beeld.
